# Indicadores Sociodemográficos de Panamá — prototipo

Prototipo funcional que acompaña la propuesta técnica del equipo Domingo Stanziola, Aralys Alvarez y Domingo Alejandro Stanziola para la consultoría nacional de UNFPA Panamá.

Ver en línea: https://dstanziola.github.io/indicadores-demo/

Fuentes: INEC, Estadísticas Vitales 2013-2024; INEC, estimación de población al 1-jul-2023 (base Censo 2023); Gabinete Social, MIDES e INEC, IPM de corregimientos 2023; UNFPA Panamá, Índice de Priorización Territorial 2026.

Este repositorio contiene solo la página publicada. No es una publicación oficial.
